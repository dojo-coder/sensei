Write the method `Hello()` of the class `HelloWorld`, which returns the string `Hello World!`.

### Rules & clarifications

- The text is exactly `Hello World!`: the capital letters, the space and the exclamation mark must match.
- The method returns the string; it does not print it.
- Write the method in `HelloWorld.cs`. Press **Run** to execute `Main.cs`, which prints what your method returns.

### Example

`HelloWorld.Hello()` returns `"Hello World!"`.
