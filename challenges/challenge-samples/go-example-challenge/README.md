Write the function `HelloWorld()`, which returns the string `Hello World!`.

### Rules & clarifications

- The text is exactly `Hello World!`: the capital letters, the space and the exclamation mark must match.
- The function returns the string; it does not print it.
- Write the function in `HelloWorld.go`. Press **Run** to execute `main.go`, which prints what your function returns.

### Example

`HelloWorld()` returns `"Hello World!"`.
