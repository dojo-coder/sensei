# Node.js FizzBuzz

A tiny, dependency-free Node.js sandbox that prints **FizzBuzz for 1..15**.

## Files
- `index.js` — exports a reusable `fizzbuzz(n)` function.
- `main.js` — the run entry; loops from 1 to 15 and prints each line.

## Run
```bash
node main.js
```

## Expected output
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
