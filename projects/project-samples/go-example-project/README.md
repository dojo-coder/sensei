# Go FizzBuzz

A small, runnable Go sandbox that prints **FizzBuzz** for the numbers 1 through 15.

- `fizzbuzz(n int) string` returns `"Fizz"` for multiples of 3, `"Buzz"` for
  multiples of 5, `"FizzBuzz"` for multiples of both, and the number otherwise.
- `main()` loops from 1 to 15 and prints each result on its own line.

## Run

```sh
go run main.go
```

Expected output:

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
