# PHP FizzBuzz

A tiny, runnable PHP terminal sandbox. It defines a `fizzbuzz($n)` helper and loops over `1..15`, printing one result per line.

## Rules

- Multiples of **3 and 5** → `FizzBuzz`
- Multiples of **3** → `Fizz`
- Multiples of **5** → `Buzz`
- Otherwise → the number itself

## Files

- `main.php` — the `fizzbuzz()` helper plus the loop that prints lines 1 through 15

## Run locally

```bash
php main.php
```

Expected output:

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
