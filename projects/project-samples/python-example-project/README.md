# Python FizzBuzz

A tiny, runnable Python sandbox that prints **FizzBuzz** for the numbers 1 through 15:

- `Fizz` when the number is divisible by 3
- `Buzz` when divisible by 5
- `FizzBuzz` when divisible by both
- the number itself otherwise

## How to run

```bash
python main.py
```

Output:

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
