# React TypeScript Image Slider

A small React + TypeScript + Vite sandbox project: a typed, styled image slider with **Previous** / **Next** controls that disable at the first and last image, plus a position counter.

## Files

- `index.html` — Vite entry point
- `index.tsx` — mounts `<App />`
- `App.tsx` — holds the image list and renders the slider
- `ImageSlider.tsx` — the reusable slider component (typed state + props)

## Run locally

```bash
npm install
npm run dev
```

Then open the printed URL and edit `App.tsx` to use your own images.
